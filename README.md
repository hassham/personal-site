# Personal Site

Built with [Astro](https://astro.build).

## Develop

```bash
npm install
npm run dev
```

Then open http://localhost:4321.

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/pages/` — routes (Home, Blog index, Blog post)
- `src/content/blog/` — blog posts as Markdown files
- `src/layouts/` — shared page layout
- `src/components/` — shared components (nav, etc.)
- `src/styles/global.css` — theme variables, base styles
